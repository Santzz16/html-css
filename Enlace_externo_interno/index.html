HTML - CSS

¿Que veremos?

Esta página está diseñada para aprender los fundamentos de HTML y CSS, dos tecnologías esenciales para la creación y diseño de páginas web. Aquí podrás conocer qué es cada una, para qué se utilizan y cómo trabajan en conjunto para construir sitios web.

A lo largo de la página se presentan conceptos básicos de HTML, encargado de organizar y estructurar el contenido de una página, y de CSS, utilizado para darle estilo, diseño y presentación. El objetivo es comprender cómo ambas tecnologías se complementan y forman la base del desarrollo web.

Este contenido está pensado como una introducción para quienes comienzan a aprender desarrollo web y quieren comprender de manera sencilla cómo se construyen las páginas que utilizamos diariamente.

Sobre HTML:

HTML (acrónimo de HyperText Markup Language o Lenguaje de Marcado de Hipertexto) es el lenguaje estándar utilizado para crear y estructurar el contenido de las páginas web. No es un lenguaje de programación, sino un lenguaje de marcado que define la jerarquía, semántica y disposición de elementos como texto, imágenes, enlaces y multimedia.

Su funcionamiento se basa en el uso de etiquetas (tags) que indican a los navegadores cómo interpretar y presentar la información al usuario. Actúa como el esqueleto fundamental de cualquier sitio web, siendo la base sobre la cual se aplican estilos visuales mediante CSS y funcionalidad dinámica mediante JavaScript.

Sobre CSS:

CSS (siglas en inglés de Cascading Style Sheets, en español: Hojas de Estilo en Cascada) es un lenguaje de diseño fundamental en el desarrollo web utilizado para definir la presentación visual de documentos escritos en lenguajes de marcado como HTML o XML.

Su función principal es separar el contenido de su forma, permitiendo controlar aspectos como colores, tipografías, márgenes, espaciado, disposición (layout) y animaciones sin alterar la estructura semántica del código. Esta separación facilita el mantenimiento, mejora la accesibilidad y permite aplicar estilos consistentes a múltiples páginas mediante un solo archivo externo.

En el desarrollo web, CSS trabaja en conjunto con otros dos lenguajes centrales:

  • HTML: Define la estructura y el contenido.
  • JavaScript: Añade interactividad y dinamismo
  • CSS: Determina la apariencia estética y el diseño visual.
